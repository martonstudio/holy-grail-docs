Changes

Build 2

New

  • SAMPLER engine with four machines: KIT (16 pads), GRAIN, STRETCH and SLICE.
  • COLOR: CLEAN, SP, S950 and CRUSH lo-fi models, with DRIVE.
  • Sample browser with PHONE, RECORDINGS and DIGITAKT. + IMPORT copies a file from iPhone Files.
  • Pull samples from the Digitakt over USB, while its transport is stopped.
  • A welcome message on first launch.
  • DIAL VALUES in settings: each knob shows its value (0-127) in its centre.
  • After the splash: the version, links to these docs and this page, and the contact address.

Changed

  • Every volume control uses the Digitakt's volume curve. 100 is unity.
  • CC assignments belong to the project. Loading a preset no longer changes them. Changing a part's engine resets them to that engine's defaults.
  • Presets no longer store CC assignments.

Fixed

  • The app no longer uses the microphone, unless MIC is ON in settings and no Digitakt is connected.
  • Synth One's OSC 1 and OSC 2 selectors pick the segment you tap.
  • Master level now starts at unity.

Note

  • Projects and presets from build 1 are replaced on update.
  • Custom CC assignments from build 1 are reset to the defaults.
