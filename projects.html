Projects

This is where you save and load your projects. Open it with PROJECT on the setup page.

ControlWhat it does
The listTap a project to select it. OPEN marks the project that is open.
SAVESaves your work into the selected project. Asks SURE? first.
LOADOpens the selected project. Unsaved work is lost. Asks SURE? first.
NEWMakes a new project and asks for its name.
SHARESends the open project's saved file.

The app keeps your work as you go, so it opens where you left it without saving.
