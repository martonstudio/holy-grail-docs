5 Projects

A project holds the sound bank and 128 patterns. The app keeps your working state automatically. A saved project is a copy of it. Like the Elektron boxes, reloading a project without saving loses your changes.

  1. On the setup page tap PROJECT.
  2. Tap a name, then SAVE or LOAD. Both ask SURE?.
  3. NEW PROJECT creates one from a name.

Patterns

A pattern, A01 to H16, keeps all settings except the looper. A Program Change on the pattern channel selects one. COPY on the setup page copies a pattern. Select another and press PASTE, which asks SURE?.
