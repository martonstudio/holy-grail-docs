5 Projects

Projects work like on the Elektron boxes. If you reload a project without saving, you lose your changes.

Save and load

A project holds the Sound bank and 128 patterns. The app keeps your working state automatically. A saved project is a copy of it.

  1. Go to the setup page.
  2. Tap PROJECT: at the top right.
  3. Tap a project name to select it. The selected name has a > in front. OPEN marks the open project.
  4. Press SAVE to store the working state onto the selected project. It asks SURE?.
  5. Or press LOAD to replace the working state with the selected project. It asks SURE?. Unsaved changes are lost.
  6. Press DONE.

NEW PROJECT: press it, type a name and press Create. The new project holds the four starting Sounds. It does not change the working state. An existing name is refused. Three names show per page. Use NEXT for more.

Patterns

A new project creates all 128 patterns for you, A01 to H16. A pattern keeps all settings except the looper. Program Change on the pattern channel selects one. See The main page.

Copy and paste a pattern

  1. Go to the setup page.
  2. Press COPY (bottom right of the CH 16 box).
  3. Select another pattern.
  4. Press PASTE. It asks SURE?. Press SURE? to confirm.
