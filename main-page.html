2 The main page

The app has four main pages. Swipe between them: main page, setup page, mixer, recorder.

What is on it

  • Top row: the four parts. Each box shows its channel (CH), the sound number and name, and a VOL fader. Tap a box to open its synth page. A dotted box is a part that is off.
  • Bottom row: FX 5 to FX 8: LOOPER, SPACE, DRIVE and HEAT. Each box shows its channel and ON or OFF. Hold a box to bypass an effect or bring it back. A bypassed box shows BYP. Tap the LOOPER box to open the looper page.
  • The playing pattern, A01 to H16, is shown large on the FX 8 box.

The LOOPER box also shows the loop state. See Looper.

Channels

Each box answers on one MIDI channel. Play a part from the Digitakt on its channel. Change a channel in the setup page. See Synths and CC assignment.

Program Change

A Program Change on a part's channel loads a sound from the sound bank. Program Change 0 loads slot 1. Program Change 126 loads slot 127.

A Program Change on the pattern channel selects a pattern. Program Change 0 is A01. Program Change 127 is H16. The default pattern channel is 16. It must match the Digitakt's PROG CHG OUT channel.

The software follows the pattern changes of the Digitakt. See Projects.

CCs

Out of the box, every CC is set to the Elektron default, CC 70 to 77. Turn an encoder on the Digitakt and the knob in the app moves. All the LFOs work from the Digitakt. You can change any CC. See Synths and CC assignment.
